# HG00096.chr20_1Mb.bam

A **real** aligned-read fixture: 2552 records from the 1000 Genomes Project's low-coverage
alignment of sample HG00096, sliced from GRCh37/hs37d5 region `20:1000000-1050000`.

Committed because every other BAM in this repo's tests is written programmatically by the tests
themselves, so nothing exercised the MD-tag reader against real aligner output. This one carries
what synthetic fixtures do not: soft clips, indels, unmapped mates, duplicate-marked reads, `N`
bases, and MD strings produced by an aligner rather than by us.

## Provenance

```bash
samtools view -b \
  https://ftp.1000genomes.ebi.ac.uk/vol1/ftp/phase3/data/HG00096/alignment/\
HG00096.mapped.ILLUMINA.bwa.GBR.low_coverage.20120522.bam \
  20:1000000-1050000 > HG00096.chr20_1Mb.bam
```

Aligned with `bwa aln`/`bwa sampe` 0.5.9-r16 against hs37d5 (per the BAM's own `@PG` lines).
Unmodified — not re-sorted, re-tagged, or subsampled.

## Known answer

`tests` in `file_tools/bam_reader.rs` assert the exact 4×4 substitution matrix this file yields.
The expected counts were computed **outside eidolon** by an awk walk over `MD` + `CIGAR`, and
independently corroborated by summing the aligner's own `NM` tags: with eidolon's skip flags
(unmapped | secondary | supplementary) the file has 2548 usable records and **804**
substitutions, and `sum(NM) - sum(inserted + deleted bases) == 804` as well.

Regenerating that oracle, if the fixture is ever replaced, is the point of writing it down —
the derivation, not just the number, is what makes the test checkable.
